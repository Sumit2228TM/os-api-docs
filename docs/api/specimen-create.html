Create Specimen

POST /rest/ng/specimens

Creates one specimen (primary, derivative, or aliquot) on a visit and returns the saved record. Use POST /rest/ng/specimens/collect when you need multiple specimens or nested children in a single call.

  • Method: POST
  • Path: /rest/ng/specimens
  • Content-Type: application/json
  • Success status: 200 OK

2. Request Parameters Reference

Omit response-only fields (cprId, ppid, computed availabilityStatus on input, etc.).

Visit, requirement, lineage

ParameterTypeRequired?Description & constraints
visitIdNumberConditionalVisit id. Required unless visitName, parent specimen, or specimen-centric cpId/cpShortTitle supplies visit.
visitNameStringConditionalAlternative to visitId.
cpId, cpShortTitleNumber / StringConditionalProtocol; with reqCode for requirement lookup; specimen-centric CP provides visit.
reqId, reqCodeNumber / StringNoPlanned requirement; copies class, type, lineage. reqCode needs CP + visit event.
lineageStringNoNew | Aliquot | Derived. Default New or from requirement.
parentId, parentLabelNumber / StringConditionalRequired for Aliquot/Derived if parent not resolved via requirement.

Specimen attributes

ParameterTypeRequired?Description & constraints
specimenClass, typeStringConditionalPVs; required without reqId (aliquot copies parent). Class may infer from type.
statusStringNoDefault Collected. Also: Pending, Missed Collection, Not Collected.
activityStatusStringNoDefault Active (Active | Disabled | Closed).
anatomicSite, laterality, pathologyStringNoPVs; aliquots use parent; else requirement or Not Specified.
biohazardsArrayNoString PV list; aliquots inherit parent.
label, additionalLabel, barcodeStringConditionalUnique if set; label required when collected + no auto-label; barcode blocked if CP auto-barcode (unless pre-barcoded requirement).
preBarcodedTubeBooleanNoRequest flag; server barcode rules also use requirement pre-barcode setting.
initialQty, availableQtyNumberConditional≥ 0; available defaults to initial; aliquot qty required if mandatory_aliquot_qty on.
concentration, freezeThawCyclesNumberNoAliquot concentration from parent if omitted; freeze-thaw ≥ 0.
externalIdsArrayNoObjects {name, value}; unique names.
comments, opComments, imageIdStringNoopComments used when closeParent is true.
uid, parentUidStringNoClient correlation ids.

Storage

ParameterTypeRequired?Description & constraints
storageLocationObjectNoOnly if Collected. Fields: id, name, barcode, positionX/positionY or position, reservationId.
containerLocation, containerTypeId, containerTypeNamemixedConditionalAuto-create box when container missing.
holdingLocation, dpIdObject / NumberConditionaldpId required with holding location.
checkout, transferUser, transferTime, transferCommentsmixedNoCheckout clears storage; transfer user via id or emailAddress.

Events & extensions

ParameterTypeRequired?Description & constraints
collectionEventObjectNoPrimary: procedure, container, user, time, comments (PVs + user).
receivedEventObjectNoreceivedQuality, user, time, comments, newLabel.

4. Error Cases

Status codeApplies toStatus message / resolution
200SuccessResource processed and saved; body is specimen JSON.
400Bad requestJSON array of errors. Business rules: missing label (SPECIMEN_LABEL_REQUIRED when collected and CP does not auto-label), duplicate label/barcode (SPECIMEN_DUP_*), missing class/type (SPECIMEN_SPECIMEN_*_REQUIRED), visit/parent (SPECIMEN_VISIT_REQUIRED, SPECIMEN_PARENT_REQUIRED), storage (STORAGE_CONTAINER_*), requirement mismatch (SPECIMEN_REQ_*). Fix fields per message.
401UnauthorizedMissing or invalid X-OS-API-TOKEN. Re-authenticate via POST /sessions.
403ForbiddenInsufficient privileges for this specimen or container. Often returned as 400 with RBAC_ACCESS_DENIED or SPECIMEN_CONTAINER_ACCESS_DENIED — grant specimen update / storage rights.
500Server errorINTERNAL_ERROR; retry or contact support.

5. Python Sample Code

Illustrative example. Replace placeholders with your base URL, credentials, and current specimen payload; do not commit secrets to source control.

Show / hide Python sample 
import requests
import json
import os

# Your OpenSpecimen REST base (include /rest/ng)
BASE_URL   = os.environ["OS_BASE_URL"]
LOGIN_NAME = os.environ["OS_LOGIN_NAME"]
PASSWORD   = os.environ["OS_PASSWORD"]
DOMAIN     = os.environ["OS_DOMAIN"]

session = requests.Session()
session.headers.update({"Content-Type": "application/json"})

auth_response = session.post(f"{BASE_URL}/sessions", json={
    "loginName": LOGIN_NAME,
    "password":  PASSWORD,
    "domainName": DOMAIN
})

auth = auth_response.json()

if auth_response.status_code == 200:
    print("Auth Successful")
    session.headers.update({"X-OS-API-TOKEN": auth["token"]})
else:
    print("Unauth Access")
    exit()

# Your current create-specimen payload (same shape as Quick Start)
payload = {
    "visitId": 1001,
    "specimenClass": "Fluid",
    "type": "Serum",
    "label": "DEMO-001-S1",
    "initialQty": 5
}

# Execute API Request
response = session.post(f"{BASE_URL}/specimens", json=payload)

if response.status_code == 200:
    print("Success:", response.json())
else:
    print(f"Error {response.status_code}:", response.text)

6. Related Endpoints

  • POST /rest/ng/specimens/collect — Collect or update many specimens, including nested children, in one call.
  • POST /rest/ng/specimens/pooled — Create a pooled specimen from multiple sources.
  • GET /rest/ng/specimens/{id} — Read back a specimen after create.
  • PUT /rest/ng/specimens/{id} — Update an existing specimen instead of creating a new one.
